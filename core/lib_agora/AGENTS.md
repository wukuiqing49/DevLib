# AGENTS.md

## 1. 范围与当前状态

本文件适用于声网 SDK 适配模块 `lib_agora`，补充项目根目录的 `AGENTS.md`。

修改前阅读本模块 `README.md`、Gradle 配置、Manifest 和已有实现。当前模块提供媒体封装，现有页面仍使用 Zego；不能把 SDK 模块编译成功描述为完成页面迁移。

当前公开 API 存在声网状态码和 VideoFrame 扩展类型。后续统一引擎与美颜接口接入时，需要将这些类型限制在适配边界，并确认实际调用方再调整 API，不为未来需求提前添加空接口。

## 2. 版本与依赖

使用根项目的 Android Library/Kotlin Android 插件版本；SDK 版本以本模块 build.gradle 为准。当前 AGP 8.11.1、Kotlin 1.9.24、Java/JVM 17、compileSdk/targetSdk 36、minSdk 23、Agora SDK 4.7.0。

Android SDK 配置继承 rootProject.ext，数值记录不替代真实根配置。不得擅自升级插件、SDK、Gradle 或 Kotlin，不建立第二套版本配置。

禁止依赖 app 或新直播页面模块。接口共享层若建立，应由本模块与页面模块共同依赖，再由宿主组装。不要通过 BaseModule 引入业务和旧引擎依赖来获取一个工具类。

SDK 使用 api 或 implementation 需根据公开签名判断；不能在仍暴露 SDK 类型时盲目改成 implementation。调整可见性前检查美颜扩展和 Java 调用方。

## 3. 职责

- 实现引擎创建、入退房、发布/订阅、预览、相机、音量、编码、屏幕共享、CDN 及诊断能力。
- 将引擎能力、异步状态与操作失败准确反馈给调用方。
- 新直播页面、座位权限、礼物、支付、登录、房间信令和外部导航由业务/宿主层处理。
- 会话参数与鉴权 URL 由宿主传入，模块不创建网络层，不请求业务 Token，不存放 App Certificate。
- 美颜帧处理扩展与具体效果实现分离，不直接引用 app 的腾讯美颜管理单例。
- 保留 README 中供应商差异说明，不能把 RTC 转推冒充 CDN 直推，或将跨频道订阅描述为云端混流。

## 4. SDK 与生命周期

SDK 方法与回调以当前版本官方文档或实际依赖的 API 为准；不要根据旧版示例猜测方法签名。新增能力需先查现有 Zego 实际调用点和相似实现。

SDK 请求成功与发布/播放实际成功分开。错误、角色切换失败、Token 失效和权限错误均需反馈，不能空 catch、忽略关键返回值或伪造成功。

使用 Application Context，避免长期持有 Activity。明确单例引擎所有权、线程约束、异步退房完成、旧回调隔离、视图解绑和重复销毁规则。

普通控制与 UI 事件按模块线程约定执行。视频帧处理遵循 SDK 线程要求，保留时间戳、变换、格式和引用计数；禁止等待主线程或在 SDK 回调内直接销毁引擎。

额外频道和 CDN 播放器必须分别管理身份、监听和释放，避免同名播放器重建或快速切房时接收到旧实例回调。

屏幕共享接收合法 MediaProjection 或 SDK 支持的授权流程；宿主负责权限与前台服务工作流。SDK 适配不能绕过 Android 的采集限制或保证所有应用可采集设备音频。

## 5. 资源与验证

SDK 模块原则上不承载直播业务 UI。确有必要的模块资源使用 `agora_` 前缀，并遵守根目录多语言、尺寸和主题规范。

不得输出 Token、证书、签名 URL 参数、用户隐私数据；日志上传仅在调用方显式触发时执行。

根据改动执行 `:lib_agora:assembleDebug` 和必要的 `:app:assembleDebug`，测试按用户要求执行。仅修改规范文件时检查文档和差异即可。

分别说明 SDK 编译、真实推拉流、美颜、屏幕共享、R8 发布包、16 KB native 兼容及包体积的验证范围。构建环境问题不得通过升级项目版本或修改发布配置绕过。
