# core_usb

来源：NASFileManager 的 `lib_usb`。保留原公开包名；功能库，不属于基础框架。

接入：`implementation project(':core:core_usb')`。Maven 坐标：`com.wkq.dev:core-usb:0.1.0-SNAPSHOT`。

SDK：compile 37、min 26、JVM 17；源码快照见 docs/import-manifest.json。通过根工程本地发布任务发布带依赖元数据和源码的产物，不复制孤立 AAR。

详细 API 和能力边界见 README.upstream.md。上游文档中的旧模块名、发布命令和坐标仅作历史参考；当前使用本页名称。NAS 的账号/权限确认、USB 的目录选择与持久授权均由宿主处理。库不承担后台队列、同步计划或权益判断。

工作台提供独立页面，可进行只读浏览、读取与显式确认的隔离写入/读回校验。USB 仅使用 SAF，不提供文件系统驱动；NAS 不保证所有固件、协议特性及大文件均已验收。未做本轮设备验证。

## 可靠性与接入边界（2026-10-27）

新建写入失败或取消时，尽力删除本次 createDocument 返回的 URI；只清理能证明归属于本次操作的文档。清理失败以 suppressed 异常附加到原错误，不覆盖取消或源读取错误。设备拔出或权限撤销可能导致清理失败，宿主需要提示并提供后续核对。

moveNew 在创建和删除源文件前检查取消，是复制后删除，不保证原子移动；源删除失败时尽力清理新目标。磁盘空间、SAF 提供方与授权状态仍由宿主管理，库不新增文件系统驱动。
