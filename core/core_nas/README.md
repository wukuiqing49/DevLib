# core_nas

来源：NASFileManager 的 `lib_nas`。保留原公开包名；功能库，不属于基础框架。

接入：`implementation project(':core:core_nas')`。Maven 坐标：`com.wkq.dev:core-nas:0.1.0-SNAPSHOT`。

SDK：compile 37、min 26、JVM 17；源码快照见 docs/import-manifest.json。通过根工程本地发布任务发布带依赖元数据和源码的产物，不复制孤立 AAR。

详细 API 和能力边界见 README.upstream.md。上游文档中的旧模块名、发布命令和坐标仅作历史参考；当前使用本页名称。NAS 的账号/权限确认、USB 的目录选择与持久授权均由宿主处理。库不承担后台队列、同步计划或权益判断。

工作台提供独立页面，可进行只读浏览、读取与显式确认的隔离写入/读回校验。USB 仅使用 SAF，不提供文件系统驱动；NAS 不保证所有固件、协议特性及大文件均已验收。未做本轮设备验证。

## 可靠性与接入边界（2026-10-27）

WebDAV 禁止自动重放网络请求，重定向保持关闭。复制每块检查线程中断；协程取消、宿主回调异常和中断不降级为普通可重试协议错误。

会话及返回流由调用者关闭，同一会话串行使用。新建写入失败可能已经在服务端留下部分文件，不能按文件名盲删或自动重试；应记录操作归属并核对后清理。账号、可信主机指纹、空间策略及后台任务由宿主提供。真实固件、网络切换和 Android 17 权限运行期表现尚未验收。
