# lib_live_beauty

来源 Starxen/lib_live_beauty。可选腾讯纹理美颜适配；只迁入库代码，不迁入业务 App 的许可证、后台地址或账号。

```groovy
implementation project(':core:lib_live_beauty')
```

宿主自行提供与第三方 SDK 匹配的授权配置。原 Starxen 的房间 UI、账号、礼物、消息等业务层不包含在本库。

本地发布坐标 `com.wkq.dev:lib-live-beauty:0.1.0-SNAPSHOT`。运行期效果与许可配置未验收，详见 `doc/testing/TEST_REPORT.md`。
