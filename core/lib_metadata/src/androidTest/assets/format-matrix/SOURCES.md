================

短文件名样本由 scripts/testing/generate_format_fixtures.py 生成，为合成色块，无私人照片数据。
带以下完整名称的样本来自 AndroidX ExifInterface 官方测试资源：

- dng_with_exif_with_xmp.dng
- heic_with_exif.heic
- jpeg_with_xmp_in_exif_first_then_separate_app1.jpg
- png_with_xmp_in_both_exif_and_itxt.png
- webp_with_anim_without_exif.webp

来源：https://github.com/androidx/androidx/tree/androidx-main/exifinterface/exifinterface/src/androidTest/res/raw
