Modified ExifTool 13.57: Exif.pm enables its existing TIFF image-data hashing for ORF.
The exact source change is included in patches/ExifTool-13.57-orf-image-hash.patch.
Native interpreter and XS modules are taken from the above repository revision.
PressIPTC modifies GNU_RELRO padding and its containing LOAD zero-padding size to end on 16KB boundaries.
Reproducible modification: scripts/normalize-native-relro.ps1 in the PressIPTC source distribution.
The script refuses changes overlapping actual writable data or another LOAD segment.
Original executables remain available at the upstream revision above.
