# Google 支付交互稿

打开 `index.html`，无需构建或外部网络。它是设计原型，不是 Android 组件，不会发起交易。

## 语言

语言选择器覆盖 14 个区域：简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语、意大利语、俄语、阿拉伯语、印地语、印尼语。巴西葡萄牙语不是葡萄牙地区的独立审校版本。

每个语言 63 个键，覆盖支付、兑换、恢复、状态反馈、说明、按钮及无障碍标签。`locales.js` 为独立语言资源；`billing.js` 不静默回退，缺键或缺少参数直接抛错；未识别的初始 `?lang=` 使用简体中文原型默认语言。常用语言是本轮明确的集合，不等于支持所有语言。

阿拉伯语切换 `lang/dir`，使用逻辑边距与价格方向隔离。所有语言价格使用相同 USD 示例金额，`Intl.NumberFormat` 仅格式化，不换算汇率；正式组件必须使用 Play 实际返回的本地化报价和周期。翻译为初稿，尚未经各语言母语人员及法律审校。

## 设计验证

```powershell
python -B design/billing/validate_locales.py
```

2026-10-30 浏览器检查：14 种语言分别切换 8 个支付状态与 5 个兑换状态，无运行时缺键；检查兑换核对中禁用重复操作。新增恢复查询状态使用独立 checking，不展示“加载商品”作为恢复结果。

320px 窄屏、主要内容 200% 字号、Activity/BottomSheet、浅色/深色的矩阵检查：56 个支付布局及 280 个兑换状态布局，横向无溢出，滚动后可达最后一个套餐。首次检查发现德语长词与俄语兑换标题溢出，已添加断词/自然换行后复查通过。它不代表所有浏览器字体、大屏、原生 Android 或 TalkBack 验收。

兑换结果通过页面外的设计状态下拉框模拟，用户界面没有伪造成功按钮。浏览器中的焦点、滚动与返回仅为原型交互，不能替代原生窗口行为。

## 文件

- `index.html`：无外部依赖的入口。
- `billing.css`：布局、主题、RTL 与文字缩放。
- `billing.js`：状态及交互编排。
- `locales.js`：所有语言资源。
- `contrast.json`：颜色对比度计算结果。
- `*.png`：主要状态截图。

原生实现现已统一进入 core_google：Activity、XPopup BottomSheet、strings 与真实 Play 调用入口；详见 core/thirdparty/core_google/README.md。原型仍使用模拟数据，不能作为真实交易验证；原生验收以 doc/testing/TEST_REPORT.md 为准。未增加 CI。
