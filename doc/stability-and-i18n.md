# 稳定性与业务英文覆盖

日期：2026-10-26。本轮维护宿主 app/feature 与本地验证工具，基础库源码保持原状。

## 稳定性修复

### 前台操作收尾

原先 DemoViewModel 在 finally 内先更新 SQLite 历史，再解除 busy。数据库写入抛错会跳过状态复位，并可能覆盖原操作的取消异常。

现在由 DemoExecution 的 finishDemoOperation 在不可取消区收尾：普通存储失败单独报告，finally 始终解除 busy，取消异常继续传播。提示附加在原结果上，保留已经生成的文件、预览和多文件结果；不自动重新执行上传或其他有副作用的操作。数据库未能写入时不冒充历史保存成功。

### 整批素材接收

原先 mapNotNull 会丢弃缺失资产，剩余非空时继续处理。现在先清空旧输入，再按请求顺序解析全部资产；空/超量/重复 ID、任意缺失记录或磁盘文件、类型不符均拒绝整批。只有全部有效才更新输入并标记已接收，失败后可重新选择重试。宿主工作区路径约束继续由 WorkspaceStore 负责，库 API 不变。

新增 JVM 测试覆盖收尾的成功、存储失败、提示回调失败、取消、取消叠加存储失败和显式取消，以及素材保序、缺失重试、删除、类型混入和批次边界。

## 英文覆盖

六个业务模块新增 24 个 values-en 文件，覆盖 362 条 string 和 7 个 string-array，保留默认中文资源。数组顺序、协议值、key 和占位符均核对一致；文件名、账号、用户输入、技术标识和服务器返回内容不机械翻译。

浏览器接收页按浏览器 zh 语言选择中文，其余选择英文；标题、按钮、等待/审批/下载/错误提示均统一取自文案表。协议路径、凭据传递和下载授权方式未改变。

目标档案通过 android.requiredHostLocales: [en] 声明宿主必需语言。聚合校验把它传给 --required-locale，即使整个语言目录不存在也会报错；string-array 同时检查覆盖、条目数量及逐项占位符。只要求本项目宿主模块，不改写历史基础库。

Debug 构建、已有与新增 JVM 测试、本地语言/源码门禁、浏览器脚本测试、本地库发布与独立消费者编译的最终结果见 [测试报告](testing/TEST_REPORT.md)。

按用户要求未做设备、真实账号购买或远程服务验证。英文长文案、小屏、横屏、大字体、RTL、深浅主题及 native 16KB 的实际设备表现仍未验收。未新增 CI；提交及推送状态以 Git 历史为准。
