# 日志操作引导实现与验证

日期：2026-11-25。需求：日志模块也使用 core_guide，帮助用户完成开启记录、返回复现、停止生成、检查并分享报告。

## 设计与实现

沿用 V3 上下文提示风格，不改原管理页、历史列表及详情功能。管理页和详情页标题栏新增 48dp 问号入口，可随时重看。初次自动展示按真实状态选择，每次前台访问最多一组，同一组实际展示后不重复自动弹出。

| 状态 | 真实目标与说明 |
| --- | --- |
| 未采集且无历史 | 采集开关、返回箭头；介绍手动开启及返回复现 |
| 正在采集 | 采集开关；介绍停止与等待整理 |
| 已有封存记录 | 滚动定位真实历史行；介绍打开报告 |
| 完整附件可用 | 分享、另存按钮；说明先检查、由用户选择接收方发送 |
| 加载、启动、整理、错误或删除 | 抑制提示，保留原错误与恢复操作 |

复用 BaseActivity、既有 ViewModel 和 BaseRecyclerViewAdapter；core_log_report 通过 implementation 组合 core_guide，后者不依赖日志模块。没有增加空模块或宿主业务协议，公开 LogReport.install/show 保持兼容。

教程绑定 Activity 生命周期，离开后取消待执行布局/展示与当前遮罩；相位改变移除过时说明。按教程 ID+版本保存 SHOWN/SKIPPED/READ，不标记业务完成，不自动切换记录或调用分享。目标每次解析真实 View，RecyclerView 先滚到相应条目。系统栏与 Insets 仍由原 Base 唯一负责。

文案提供英文和简体中文，其他语言 fallback 沿用现状；没有宣称 LensDock 全部语言已补齐。源码风格自查复用语义色、矢量图标、48dp 入口及现有 V3 排版；用户视觉认可与实机矩阵另记。

## LensDock 实际入口

LensDock「我的 → 日志上报」原本直接调用 LogReport.show；因此本轮在库内同一真实 Activity 接入教程，消费项目更新版本即生效，既有埋点、初始化及相机快照保留。新 JitPack 标签为 `log-v0.1.1`，日志与引导模块使用相同发布标签，避免直接/传递引用版本分歧。远程发布及 LensDock 构建结果完成后另补。
