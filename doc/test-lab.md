# Demo 使用说明

当前 19 个 core 模块对应 18 个演示入口：8 个基础模块、10 个功能库。lib_operations 是内部支撑，通过图片、PDF、压缩与二维码流程覆盖，不单列业务页面。

页面继承 BaseVMTitleActivity / BaseViewModel，使用现有样式、DialogKit / XPopup、Utils 选择器与 Router。基础库源码不因演示而改造。导入限制：最多 20 个文件、每个 128 MiB、合计 256 MiB；耗时任务可取消。

| 类型 | 模块 | 流程 | 条件 |
| --- | --- | --- | --- |
| 功能库 | `core_google` | 登录与购买两条独立流程：配置 Web Client ID、Google / Firebase 登录、会话与退出；配置商品、查询真实报价、选择确认购买、恢复状态。 | 需要 OAuth / Firebase / Play 测试配置；未做真实交易 |
| 功能库 | `core_pdf` | 图片 PDF 编排：按选择顺序组合多张图片，设置纸张、方向和网格。先配置再导出，结果显示 PDF 首页。 | 本地流程 |
| 功能库 | `lib_document` | Office 报告编辑：编辑标题、正文和表格。分别生成 DOCX 与 XLSX，使用外部阅读器检查版式。 | 本地流程 |
| 功能库 | `core_image_render` | 图片处理工作台：文字水印、四种相框、四种样机背景、签名提取、文字批注及撤销/重做，导出 PNG 副本。批注使用预设归一化位置，不宣称完整自由绘制编辑器。 | 本地流程 |
| 功能库 | `core_qrcode` | 二维码生成与识别：编辑内容、颜色及尺寸生成二维码；也可选择图片识别。生成后回读验证，再提供导出。 | 本地流程 |
| 功能库 | `lib_metadata` | 照片元数据：先查看 EXIF/IPTC/XMP 字段分组，再把编辑写入副本并回读。只处理副本，不改用户原图。 | 本地流程 |
| 基础库 | `core_base` | 基础页面与状态：本页直接继承 BaseVMTitleActivity。演示 BaseViewModel 的加载、空态、错误、恢复和一次性确认事件。 | 本地流程 |
| 基础库 | `core_utils` | 文件与 URI 工具：使用基础库选择器导入文件，查看文件摘要与可访问性。文件保留原始内容，输出可复制核对。 | 本地流程 |
| 基础库 | `lib_xpopup` | 弹窗交互：编辑弹窗标题和内容，分别体验通用 DialogKit、确认回调和 XPopup 底部选择。 | 本地流程 |
| 基础库 | `core_network` | HTTPS 请求与响应：配置自己的 HTTPS JSON 接口，使用 Network 库初始化和统一响应封装；失败可以修改地址重试。 | 本地流程 |
| 基础库 | `core_router_api` | 路由跳转与参数：输入已注册路径和参数，使用 Router 打开目标页。可以尝试不存在的路径检查降级。 | 本地流程 |
| 基础库 | `core_router_annotation` | 注解与参数注入：查看 Route / Param 实际作用：编辑参数，打开已注解的目标页，确认生成注入器读取结果。 | 本地流程 |
| 基础库 | `core_router_processor` | KSP 生成验证：本模块编译时运行真实 KSP。查看生成类及路由注册，再打开生成的路由目标验证。 | 构建期验证 |
| 基础库 | `core_router_gradle_plugin` | Gradle 插件接入：Gradle 插件在构建阶段执行。此页展示独立消费工程接入方式与当前路由生成结果，不在手机上伪造编译。 | 构建期验证 |
| 功能库 | `core_archive` | 压缩与加密归档：选择多个文件创建 ZIP，可设置密码；选择加密 ZIP 后输入密码解压，展示实际条目与校验结果。 | 本地流程 |
| 功能库 | `lib_upload` | 多协议上传：选择协议与服务器，先测试连接，再显式上传所选文件。凭据只保留在当前页面，不保存、不输出到日志。 | 需要服务器 |
| 功能库 | `lib_transfer` | 持久文件传输：选择文件并配置应用本地、SMB、HTTPS WebDAV 或 SFTP 目标；远程目标先只读测试再确认创建任务。自动观察最近 50 个演示任务，持久保存选择，支持查看、暂停、恢复和取消。 | 本地或自有远端 |
| 功能库 | `lib_drop` | 浏览器文件发送：选择本次分享文件，选择明确的局域网监听地址。浏览器接入后核对请求编号，逐个选择并确认批准或拒绝配对，查看会话进度并停止。离开页面关闭会话。 | 需要局域网接收端 |

局域网接收使用 feature_demo_files 自带的最小示例页，支持连接申请、手机批准、分页文件列表和原生下载。不再依赖 lib_html，也不提供原产品的 WebSocket 测速等完整网页功能。发送端退到后台即停止服务；HTTP 不加密，外部网络与浏览器行为本轮未实测。

上传只提供 FTP/FTPS/HTTP；SMB/SFTP/WebDAV 使用文件传输。上传服务器和 NAS 凭据由使用者提供，示例不会自动连接。lib_metadata 仍有 Native 依赖；二维码库仍声明 CAMERA 供扫码能力使用，移除拍照库不等于移除所有扫码能力。

本轮不运行设备测试。编译通过不代表真实服务器、跨设备下载、媒体授权或 Native 格式处理通过。

## 2026-10-26 交互与恢复优化

- Google：Play 购买页面关闭、返回 Demo 时主动同步购买状态；回调也触发同步。查询超时或不可用时保留“无法确认”提示，不伪装成免费或已购买。报价和购买流程保持显式操作。
- Transfer：历史来自底层数据库，不依赖页面内存 taskId；重进页面恢复最近选择。界面仅控制本演示创建的任务。远程连接的地址/账号会存储，密码交给传输库加密保存，用于后台任务恢复；密码输入框不参与 View 状态保存。
- Drop：批准与拒绝一次只作用于明确选中的请求；手机与浏览器都展示请求编号。过期或会话关闭后操作失效。离开页面仍停止服务。
- Upload：FTPS/FTP/HTTPS 选择器替代协议字符串，端口与 URL 校验，配置变更需重新成功测试；凭据只在页面/ViewModel 生命周期内保留，不持久化。
- 图片：五条处理路径均调用已有引擎，取消信号传入引擎；文字批注最多 20 层，历史最多 30 个状态，原图保持不变。
- 公共错误：仅显示输入、权限、文件不存在、超时、证书或网络等分类，不输出底层异常消息。

这些变更经过本地 JVM 与构建检查，不代表字体缩放、深浅主题、旋转、系统栏、真实服务器或账号链路已经完成设备验收。
