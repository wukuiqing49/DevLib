# DevLib 开发者能力工作台

App 包名保持 com.wkq.dev。当前共 19 个模块（8 个基础、10 个功能、1 个内部支撑），库公开 API 不变；产品编排、资产与操作记录在 feature，基础库保持原实现。源码目录沿用 feature_demo_* 命名，避免无收益的全量改名。

## 一级入口

| 入口 | 内容 |
| --- | --- |
| 功能库 | 默认首页，完整展示 10 个功能库，按文件与传输、图片、文档、Google 分类；每项提供体验与独立接入详情 |
| 基础组件 | 5 套体系：Base、Utils、Network、Routers、XPopup；Routers 详情中切换 API、注解、KSP 处理器和 Gradle 插件，共覆盖 8 个基础模块 |
| 工作区 | 文件与操作记录两个内部页面；素材/产物筛选、缩略图、批量流转、打开/分享/另存和改显示名称 |

顶层 CatalogFragment 只管理子 Fragment 导航；库目录 LibraryListFragment 的两份实例与 WorkspaceFragment 分别持有独立 ViewModel。顶层切换不清空查询或分类，不重复创建页面；工作区文件与历史保留各自搜索和滚动状态。系统重建后的恢复仍需运行验证。

常用与最近合并去重为最多 6 个轻量快捷入口，不再复制整张卡片。基础与功能目录不重叠；库模块名、运行条件在目录可见，完整介绍、依赖与边界进入 LibraryDetailActivity。构建插件不展示错误的运行时 implementation，处理器使用 ksp。

## 文件到产物

设备文件 → 有大小限制的应用私有副本 → 工具配置 → 执行 → 工作区产物 → 打开、分享、另存或继续交给另一工具。

导入保留原始显示名称，新副本在独立目录中使用清理后的原文件名，避免压缩包内容全部变成 UUID。资产 ID 在 SQLite 中持久化，页面间传 ID，不接受任意文件路径；读取时检查文件仍存在且位于宿主共享目录。图片工具只接受支持的图片扩展名，文件工具接受通用文件。旧文件不会被自动扫描成新产物。

用户在设备选择器中导入可一次选择多个文件；工具内“从工作区选择”目前一次选择一个，文件中心可选择最多 20 项后批量送入工具。接收时缺少任一已选资产、磁盘文件消失或混入不支持的类型，整批拒绝并清空旧输入，不静默处理部分输入；成功后才标记已接收，失败允许重新选择重试。

所有生成产物保留原文件，副本可另存到系统文档位置。工作区属于应用私有数据，卸载会清除。文件中心显示最近 300 个有效资产与最近 100 条操作，并非完整文件管理器；本轮未增加批量删除，避免误删其他操作引用的文件。

## 独立业务流程

- 图片工作台：真实输入与输出预览、五类已有渲染能力、参数配置、PNG 输出及后续流转。文字批注仍使用预设位置，不宣传为自由画布编辑器。
- PDF：图片素材缩略图、逐项上移/下移/移除、纸张/方向/布局配置与导出。当前入口是图片生成 PDF，不宣传为任意 PDF 页面编辑器。
- 文档：标题、正文与真实单元格表格编辑，可增删行列，最多 30 行/8 列；逗号和换行保留在单元格内，不再用 CSV 文本框模拟表格。使用 SavedStateHandle 保留表格编辑状态，系统恢复仍需设备验证。
- 元数据：EXIF 常用字段、JPEG 的常用 IPTC/XMP 内容字段详情，作者与描述写入副本并确认；不冒充全标准、全格式元数据编辑器。
- 归档：导入文件、压缩或解压，多个解压文件分别登记为产物，可逐个打开/保存或批量继续处理。
- 传输/上传/分享：保留连接测试、任务控制、显式确认、单项配对审批及独立服务配置。连接、网络和真实跨端链路仍需对应环境验证。

## 状态与责任

WorkspaceStore 保存资产、前台操作记录、输入/输出关联、收藏与最近使用。前台操作会记录运行、完成、失败、取消状态；进程重新启动时，未完成前台记录标记为中断，不会自动重跑。点击历史操作只能重新打开配置页面，不自动重放上传或购买。历史收尾写入失败会附加独立提示，保留当前产物并解除忙碌状态，不能仅因记录失败自动重提操作。

core_nas 与 core_usb 提供前台 NAS / SAF 操作，不包含后台队列。上传和测试需确认，凭据不进入操作历史；下载结果使用工作区保存及分享。

Base Activity/Fragment/ViewModel/Adapter、路由和 XPopup 继续复用；MainActivity/BaseTitleActivity 是系统栏 Insets owner，底部 Material 导航不重复添加系统栏边距。UI 层观察业务状态，文件和数据库访问在 IO 调度器。

## 验证边界

测试命令与实际结果见 testing/TEST_REPORT.md。新增 JVM 用例覆盖资产目录边界、流转筛选和表格编辑模型；本地 SQLite 引擎可检查 SQL 结构，但不能代替 Android 数据库设备验收。

设备验证遵循 executionPolicy，用户明确授权时仅执行对应范围。当前导航已在 Pixel 8 抽查；字体放大、平板、旋转、系统文档选择器、进程重建以及真实账号/交易/服务器连接不能由编译或导航冒烟推定。本轮不创建或调整 CI；提交推送仅按用户明确授权执行。

## 业务语言

工作台及六个业务模块提供英文资源，中文使用默认资源回退。协议/样式下拉数组同样有英文版本，保持选项顺序与业务枚举一致。局域网浏览器接收页按浏览器语言选择中文或英文；不修改用户文件名、账号、服务器数据或技术标识。宿主语言门禁要求 en 目录存在，并检查 key 与占位符；这不代表基础库全部历史文案或设备视觉已验收。
