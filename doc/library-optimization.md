# 独立库可靠性优化

日期：2026-10-27。当前 20 模块：8 基础、11 功能、1 内部支撑；16 AAR、4 JVM JAR。基础库源码保持原样，原仓库不写入。以下为本次明确修改与已检查边界，不代表设备或生产验收完成。

## 工作台与接入

工作台维持 19 个库入口，lib_operations 无独立页面。基础库示例与构建工具说明页按真实用途展示，不制造空业务流程。现有功能页继续复用 XML/ViewBinding/MVVM、Base 与统一输入/进度/产物/历史机制。

共享错误呈现增加预算、冲突、格式、取消与文件 IO 的中英文提示；普通文件 IO 不再统一提示网络错误。底层异常原文不直接展示，避免泄漏服务器地址、凭据或 token。Base 仍是唯一 Insets 处理方，本次未重建主题或窗口封装。

core 的协议实现保持独立：HTTP 通用接口为 core_network，FTP/FTPS/HTTP 上传为 lib_upload，SMB/WebDAV/SFTP 为 core_nas，SAF 为 core_usb，浏览器分享服务为 lib_drop。底层文件流和 HTTP 依赖相同不代表业务职责重复。本轮不恢复 lib_transfer、lib_html、分散认证支付库或已排除来源。

## 兼容与行为说明

保留公开包名和方法签名；可靠性校验可能让过去被接受的危险输入明确失败。订阅查询未知结果现在抛错，宿主不得据此撤销既有权益；到期时间 0 表示未知。Office 文件系统不支持原子移动时失败而非先删除旧文件。USB 失败清理是尽力而为，拔盘或撤权时不能保证成功。

本次没有升级生产 SDK 依赖，没有新增 CI，没有运行设备命令，也不自动提交或推送。测试范围和最终结果见 [固定测试报告](testing/TEST_REPORT.md)。
