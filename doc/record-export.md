# 统一记录三格式导出

## 当前结构

`core_document` 合并原 `core_pdf` 和 `lib_document`，成为唯一文档功能库，保留旧公开 Kotlin 包名。当前工程 19 个 core 模块（8 基础、10 功能、1 内部支撑），目录 18 个库能力入口；记录页面内另保留图片 PDF 子流程。

库只接收通用 `ExportRecord`：标题、宿主格式化的时间、字段、备注、矩形明细和图片附件，以及公司、个人、多人签署和模板快照。业务产品决定记录含义及文案，不迁入原产品模板、价格或 Pro 判断。详见 [库接入](../core/functional/core_document/README.md)。

## 工作台流程

记录内容 → 时间与备注 → 明细单元格编辑 → 选择图片 → 配置资料／模板／水印 → PDF 首页预览 → 三格式或单格式导出 → 选择产物查看、分享、另存或流转。

- PDF、Excel、Word 使用点击时同一份记录快照；Excel 不再丢弃备注，Word 标题使用已有标题样式。
- 表格首行为表头，页面最多 30 行、8 列、每格 512 字符（控制页面恢复状态体积）；数字默认按文本保留，显式开启数值后明细中的可解析数字写成数字。高精度编号需关闭数字开关。
- 附件目前仅支持 JPEG/PNG，最多 20 张，标题、时间与备注均进入三个文件。
- 批量原子发布；失败和取消不把半批文件登记为成功。取消通过 runInterruptible 连接现有线程中断检查。
- 使用 DemoActivity → BaseVMTitleActivity、DemoViewModel → BaseViewModel、BaseRecyclerViewAdapter；单元格改为 XML/ViewBinding 和统一输入样式。基础库源码不动。
- 普通 Edge-to-edge 沿用 Base，top/bottom/IME Insets 由现有 Base owner 处理，不重复添加系统栏避让；页面滚动，单元格区域横向滚动，使用现有深浅主题资源。
- 原 Office 和图片 PDF 路由保留，兼容历史操作记录。模块名与坐标改为 core_document / core-document；旧 Maven 坐标不再同时引入。消费者必须更新 Gradle 依赖，纯 JVM 接入改为 Android AAR。

## 验证边界

当前本地回归命令与结果见 [固定测试报告](testing/TEST_REPORT.md)。JVM 内容/事务与构建检查不能证明真实 PDF 字体、阅读器兼容或分页视觉正确。未执行设备、外部分享或 Word/Excel/WPS/LibreOffice 人工打开验收；不创建或调整 CI，不自动提交推送。

## 资料与自定义模板

记录页进入「公司／个人／签名／模板与水印」：

- 公司：名称、地址、电话、邮箱、网站、登记编号、Logo。
- 个人：姓名、角色、单位、电话、邮箱、头像。
- 签署：姓名、角色、时间、说明、签名图片；点击加入/更新后进入签署列表，可选中编辑、删除或新增多人。当前提供图片导入，不提供证书数字签名。
- 模板：内置标准、明细、图文三类；新建、选择、复制、编辑、删除（至少保留一个）、导入/导出 JSON。导入分配新 ID，不覆盖本地模板。交换文件含图片水印，不含资料和签名。
- 布局：区块显示/隐藏、上下排序和标签，字段筛选、明细列顺序、照片列数。字段级标签可通过模板 JSON 的 fieldLabels 编辑。
- 样式：主色、表头底色、标题/正文字号、页边距、横竖向、页眉页脚和页码。
- 水印：无/文字/图片、透明度、角度、宽度、相对位置、首页/每页。Excel 按工作表打印页处理，实际阅读器/打印效果待验收。
- 预览：保存配置后返回当前记录生成真实 PDF 首页预览，打开文件检查完整分页；不是 Word/Excel 的所见即所得预览。

表单采用分组折叠、XML/ViewBinding 与既有输入样式；图片预览复用 ImageLoaderUtil。当前会话字段、区块顺序、资产选择和多人签署保存轻量恢复状态，旋转/进程死亡的实际 UI 端到端验证未执行。

每次生成先复制记录图片、Logo、头像、签名和水印，保留资料与模板版本元数据。`RecordSnapshot.restore` 可恢复同一份历史内容重新导出；默认资料及模板后续变化不会覆盖旧文件。

## 来源核对与范围

核对 RoofQuote 的原 ReportTemplateModel、Word/Excel 写入器，以及 SiteReport 的 SignatureProfileEntity。恢复通用公司/提交人/签名与水印能力；不引入原屋顶计价区块、数据库表、Pro 模板层级、SiteReport 业务模板或账号体系，原仓库未修改。

自定义模板是结构化记录模板，不支持导入任意 Office 文件做占位符替换，也不是自由坐标拖拽设计器。签署是资料与签名图展示，不包含 PKI 验签。PDF 表格跨页不自动重复表头，实际中文字体、长内容、签名排版及 Excel 打印需人工确认。
