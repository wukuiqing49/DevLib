# core_guide 实现交接

日期：2026-11-25。依据当前会话：通用库、模块名 core_guide、文字换行、主题颜色、动画、沉浸式与全屏，compileSdk/演示宿主 targetSdk 37，兼容 API 35 边到边。只实现通用库和 DevLib 演示，不改 LensDock 的业务提示策略。

## 范围与组件

- `core/functional/core_guide`：独立 Android Library，AndroidX Core/Lifecycle/Activity，XML + ViewBinding 的默认提示布局；不新建 Activity、Fragment 或业务 ViewModel，因此库无 Base 继承要求。
- `FeatureGuide`：入口与单容器会话替换；显式生命周期、可选返回分发器。
- `GuideOverlay`：页内遮罩、高亮、提示定位、点击策略、动画和资源释放。
- `GuideModels`：目标、样式、颜色、动作、回调与结果契约。
- `GuidePlacement`：安全区域内上下定位、底部降级；纯几何可测试。
- `GuideHistory`：可选阅读/业务完成记录，不决定触发时机。
- 演示页：复用 `DemoActivity`、`DemoViewModel`、工作台 XML 和 KSP 路由，入口 `/files/core_guide`。六个实际交互入口，不引入产品品牌。

## 信息与视觉

目标保持原样，背景半透明中性遮罩；默认提示采用宿主主题背景、标题/正文/主次操作颜色，缺省有日夜配对资源。标题、正文自然换行，段落保留；正文可滚动，按钮纵向排列以容纳长译文。可覆盖全局或单步样式，也可提供完整自定义卡片。高亮圆角矩形优先用于卡片和按钮，圆形适用于图标；少量强调动画，可全部关闭。

## 窗口与输入责任

宿主是唯一 Window 策略负责人：边到边、全屏、系统栏明暗、权限弹窗与窗口模式均由宿主维护。库不修改这些属性，只计算自身安全区；Insets 不消费、不叠加至宿主。目标屏幕位置转换为覆盖层局部坐标。独立 Dialog/Popup 必须挂到自己的窗口/容器。

默认遮罩拦截输入，真实控件点击必须显式启用，不转发合成触摸。返回优先关闭引导；跳过、完成、销毁、替换、目标不可用分别报告。宿主业务状态不受引导下一步影响。列表目标由宿主先滚动/展开；等待有上限。

## 状态与恢复

未启动/等待目标 → 当前步可见 → 下一步或上一步 → 阅读完成/跳过/退出。停止时隐藏，恢复重新定位；销毁立即释放。旋转重建由宿主保存稳定步骤 ID 并用新 View 重新接入，不序列化 View 或 Context。等待失败返回可追踪结果。旧句柄不影响替换后的新会话，回调重入也不堆叠遮罩。

## 验收条件

1. 其他项目可只引用该 AAR 和 AndroidX 依赖编译，不依赖 DevLib Base 或业务模块。
2. 主线程会话可前进、后退、跳过、销毁，结束只通知一次；目标缺失不会无限等待。
3. 长中文/英文与主动换行不被截断，深浅主题和主按钮前景可配置；小窗口按钮可通过滚动到达。
4. 系统关闭动画时尊重设置，快速切换和生命周期结束不残留动画/监听。
5. 不改宿主 padding/Window flags；覆盖层跟随当前窗口与可见 Insets。
6. API 26、35、36、37、手势/三键、刘海、IME、读屏、RTL、大字体、横屏/分屏/桌面窗口纳入待运行矩阵。构建/JVM 不等于这些场景实机通过。
