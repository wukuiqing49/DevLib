# 视频策划简报模板 (Video Brief Template)

```markdown
## 项目基础信息
- **产品/主题名称**：[本轮产品名称及真实功能依据]
- **核心诉求/目标**：[例如：Google Play 宣传片 / 社交媒体种草视频 / 功能演示]
- **目标受众**：[例如：摄影师、独立摄影爱好者、注重隐私的 Android 用户]
- **目标总时长**：[例如：30s / 45s / 60s]
- **目标画幅**：[16:9 横屏 (1920x1080) / 9:16 竖屏 (1080x1920)]

## 视觉与风格基调
- **主选风格**：[引用 references/styles/ 中的风格卡片，如 06-motion-design-ad 或 01-cinematic]
- **色彩与氛围**：[例如：科技深蓝、极简冷色调、高饱和活力等]
- **节奏与配乐**：[例如：快节奏节奏点踩点 / 舒缓叙事流]

## 关键主体与连续性要求
- **主要角色/人物**：[是否有固定角色？是否有已注册的角色参考图或 Character ID？]
- **核心产品/道具**：[是否有真实 UI 截图、产品实物定妆图需要贯穿？]
- **首尾帧衔接需求**：[是否需要镜头间画面连贯（Frame Continuation）？]

## 交付与预算门禁
- **预算上限/消耗上限**：[例如：最多消耗 100 Credits / 预算额度]
- **首选执行后端**：[Google Flow MCP / 开放 API / 本地 ComfyUI / 手工辅助]
- **交付格式**：[MP4, H.264, 1080p, 24/30fps]
```

预算同时记录授权范围/会话依据、费用单位、在途费用、每镜头尝试上限与后端版本。使用已有授权，不为已确认参数重复提问。生成片段、实录和后期合成分别标注。
