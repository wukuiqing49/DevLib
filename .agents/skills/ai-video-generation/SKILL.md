# AI 视频生成

将创意转为可追踪分镜、经审核片段和本地成片。先检查真实可用的生成工具与媒体环境，不把平台名称或排队成功当成可执行能力或交付结果。

## Google Flow 使用方式

用户指定 Google Flow 时，使用 Flow 作为生成通道；先检查实际可用的 Flow MCP 或浏览器入口，不自动改用其他平台。复用当前会话已明确的账号、模型和生成授权，不把 Skill 安装等同于可调用的 Flow 服务。

单段视频可直接交付经回读的 Flow 原片；仅在拼接、提帧、字幕或音频处理时检查和使用本地媒体工具。FFmpeg/ffprobe 缺失不阻止已授权的 Flow 策划和生成，只标明受阻的本地后期步骤。Flow 原片的对白、音效与配乐先试听保留，再按要求混音或替换。

## 策划与素材

- 用 [简报](templates/brief.md) 记录目标、受众、画幅、总时长、风格与交付参数。复用会话已明确的选择；只询问影响结果的缺项，已授权的素材整理和分镜编写继续推进。
- 用 [分镜模板](templates/shot-plan.md) 按总时长和后端支持时长拆镜头。4～8 秒是常用建议，不限制镜头数；60 秒可以拆成更多镜头或使用后端支持的长镜头，最终校验总时长。
- [风格卡片](references/styles/01-cinematic.md) 所在目录提供可选方向，不强制套用某种风格。按需读取 [提示词指南](references/prompt-craft.md)。负向提示词、参考图和首尾帧仅在当前后端支持时使用。
- 产品界面、文字、Logo、商店徽章优先使用真实录屏或确定性后期合成。真实截图作为生成参考不保证生成结果真实；AI 场景不得冒充实际功能证据。需要发布时将成片与素材授权证据交给项目现有发布流程。
- 按 [一致性指南](references/continuity.md) 区分连续动作与独立剪辑。只有连续动作镜头才使用上一镜头尾帧；不同场景、景别或 CTA 不强制承接尾帧。

## 生成与恢复

读取 [后端适配](references/provider-adapters.md)，发现当前工具/API 的真实参数、版本、支持尺寸时长与计费方式。抽象动作是编排语义，不是可以直接调用的工具名。

用 [清单](templates/manifest.json) 跟踪来源、生成任务和候选；路径统一相对清单所在目录，数组顺序即剪辑顺序。记录用户授权的后端、范围、预算单位、累计消耗、待结算消耗及每镜头最大尝试次数。无凭据写入清单。

提交前展示或核对参数、报价依据与授权范围。已有明确预算授权时，在范围内直接继续，不逐镜头重复询问；未获授权、超额度、价格不明或更换计费后端时先补齐必要确认。默认每镜头最多两次生成尝试，第二次也必须在预算范围内；用户指定次数优先。没有授权重试时，失败后报告原因与具体重试方案。

默认逐镜头执行以控制依赖和消耗。提交后立刻记录任务 ID；超时或结果不明先查询原任务，不直接重提。记录失败、取消、退款和实际费用，退款仅在已确认时抵扣。达到预算或尝试上限停止生成，但继续整理已有产物和失败证据。质检失败不得无限重生成。

## 质检与交付

- 下载到对应任务/候选的独立路径，核对任务归属、可解码性、时长与尺寸。保留原片，不用“最近一次生成”猜对应关系。
- 回读视频，检查人物、产品文字、动作、卡顿、黑帧和镜头接点；在清单中记录证据及结论。只有实际通过的选定候选将 `status` 与 `render_output.review_status` 同时设为 `approved`。
- 依照 [拼接指南](references/assembly.md) 提帧和合成。工具依赖 Python 3.10+、FFmpeg 与 ffprobe；FFmpeg 可来自 imageio-ffmpeg，ffprobe 需另行可用。支持环境变量 `FFMPEG_EXE` / `FFPROBE_EXE`，本地路径不写入共享清单。
- 拼接脚本拒绝遗漏或未审核镜头，读取目标尺寸与帧率，保留原声；BGM 可混音或替换。通过解码、尺寸和时长检查后原子交付，不把损坏候选覆盖到已有成片。
- 最终还需实际观看与听音，核对文字、接点、音量、音画同步、素材许可。脚本通过只证明媒体结构检查，不证明视觉或发布验收通过。

本地验证：`python -B -m unittest discover -s <skill目录>/scripts -p "test_*.py"`。维护时使用 [行为案例](references/evaluation-cases.md)，报告实测、人工推演与未验证项，不创建 CI 或提交真实生成任务来替代本地检查。
