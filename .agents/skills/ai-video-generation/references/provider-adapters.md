# 生成后端适配

先发现当前环境可用工具并读取其 schema；HTTP 后端核对当前官方文档及实际 SDK。记录后端、模型/版本、工具/API 版本或文档日期、支持的时长/比例/参考帧能力。未发现真实通道时先交付分镜和提示词，再明确生成受阻，不虚构工具名。

## 通用任务契约

以下是语义步骤，不是统一 API：

1. 准备：确认模型能力、素材授权、画幅、时长及候选数量， unsupported 参数在提交前处理。
2. 报价：记录金额/点数单位、报价来源与有效时间。把已花费和在途费用都计入预算；不可凭空估价。复用会话已有授权，只在缺授权或超范围时询问。
3. 提交：保存任务 ID、请求指纹/幂等键（后端支持时）、提交时间、尝试序号和估计费用。拒绝将网络超时自动当成未提交。
4. 查询：使用原任务 ID，按后端限流建议退避；持续失败记录受阻并退出轮询。取消是否停止计费以实际结果为准。
5. 下载：按任务与候选 ID 取得指定产物，校验可解码、尺寸和时长并登记本地路径。下载失败可重试下载，不重新生成。只下载授权产物，遵守当前工具的媒体访问限制。
6. 复核：保存质检结论；重生成计为新尝试并重新核对剩余额度。保持原任务与候选记录，不覆盖历史。

## 平台适配选择

- **Flow MCP**：仅调用实际发现的工具。核对准备与提交是否分离、确认调用是否扣费、任务查询和指定资产下载方式。不要假定存在 `flow_create_character` 等接口；角色参考能力以 schema 为准。
- **Kling / Sora / Runway API**：各平台认证、请求字段、终态名称、图片上传方式和计费不同，不共用假定 JSON。使用当前官方接口说明，对应实际任务 ID 和资产 ID。
- **ComfyUI**：先检查所需模型、节点、工作流及本地资源；保存 workflow 版本、prompt ID 与输出文件映射。复制已完成产物到工作目录，不移动或重命名服务端共享输出。不默认本地计算完全无成本。
- **网页/人机协同**：使用当前可用且获授权的浏览器工具，或提供明确的人工作业包。没有工具时不假定存在 Browser Subagent。付费提交沿用同一授权和预算规则。

任何后端都只在本轮明确授权的范围内运行；切换平台或套餐不自动沿用不兼容的费用单位。
