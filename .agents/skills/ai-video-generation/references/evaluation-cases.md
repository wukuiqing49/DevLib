# 行为验证案例

维护后按受影响范围验证。媒体用例运行 scripts/test_media.py；生成服务案例仅做流程推演，除非另获真实生成授权，不提交付费任务。

| 输入场景 | 应观察到的行为 | 验证方式 |
| --- | --- | --- |
| 竖屏输入含横屏、不同帧率、有声和无声片段 | 输出指定竖屏、统一帧率，保留有声片段原声 | 本地合成媒体测试 |
| 音乐比视频短 | 循环音乐且视频总时长不被截断 | 本地媒体测试 |
| BGM mix / replace | mix 可检测原声和音乐；replace 不保留原声 | PCM 频率能量检测 |
| 缺镜头、审核 pending、重复 ID | 整体失败，不能静默交付部分片段 | 清单测试 |
| 坏源片、缺 BGM、目标时长不匹配 | 非零退出/异常，已有成片不变 | 本地媒体测试 |
| 单引号/中文路径 | 正常拼接，不破坏 concat 语法 | 本地媒体测试 |
| 1fps 尾帧、越界时间戳、旧输出存在 | 提取实际最后一帧；非法参数失败且旧图不变 | 本地媒体测试 |
| 用户已授权指定平台总预算和两次尝试 | 范围内不重复询问；在途费用计入额度 | 人工流程推演 |
| 提交超时但可能扣费 | 查询同一任务，不重新提交；达到尝试上限停止 | 人工流程推演 |
| 60 秒产品视频且无可用生成工具 | 合理拆镜头，先交付策划；明确生成受阻，无虚构接口 | 人工流程推演 |
| UI 功能/Logo 必须真实 | 用录屏/合成，生成场景不冒充功能证据 | 素材和成片人工审查 |

通过 Python 测试不能证明视觉自然、产品真实、预算接口或远端生成成功。实际结果写入本轮交付说明，不能预填通过。
