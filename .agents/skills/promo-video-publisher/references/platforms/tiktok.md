# TikTok

Confirm the account, target post type and chosen file at each step. Gallery, editor and publishing screens can all have a Next action; observe after every transition to avoid publishing a Story unintentionally.

Before posting, inspect the full description, selected cover and actual text overlays. Processing may temporarily hide editing or sharing controls. Inspect current posts and drafts before retrying.

For existing-post edits, confirm the current edit capability and any frequency restriction in the client. Repeated restriction messages are a stopping condition, not a reason to reupload. Follow the common recovery rules if a replacement is necessary.

Inspect the account's available website and comment controls. Do not infer ordinary-post capabilities from LIVE, advertising or creator-marketplace features. Do not switch account type to obtain a link without authorization. Pinning and URL clickability need separate checks.

Use current official [TikTok support](https://support.tiktok.com/) and the actual account UI for feature-specific decisions. If official guidance does not settle a capability, describe the observed account/client behavior without claiming a universal rule.
