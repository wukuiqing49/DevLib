# YouTube and Shorts

Confirm the channel and the actual video type. Match an existing video by ID/share link, title and imagery. A different URL format does not establish a different content type.

When phone operation is requested, prefer an already available YouTube Studio app for titles and detailed descriptions. Use the YouTube app for the viewing page, author comments and applicable cover controls. Check both apps belong to the intended channel. A browser Studio session can require separate authentication; do not treat that as a prerequisite when an appropriate native entry is available. Installation or account changes must be within scope.

Determine current Shorts cover-frame, thumbnail and caption-track support from official guidance and the actual client. Do not assume every Studio client provides every editing field. Inspect inherited upload defaults for another product's copy. Set audience and applicable language/category fields according to actual content and available controls; report fields not configured.

Verify link capabilities separately for long-form descriptions, Shorts, comments, channel links and related videos. Check current pinning eligibility rather than inferring it from phone-number verification. Treat saved text, clickability and pinning as independent results.

Starting points for current official guidance:
- [Edit video settings](https://support.google.com/youtubecreatorstudio/answer/57404)
- [Links and clickable locations](https://support.google.com/youtube/answer/13748639)
- [Comments and pinning](https://support.google.com/youtube/answer/6000964)

Use the common publishing checklist for description/comment delivery and post-publication verification; do not maintain a second copy here.
