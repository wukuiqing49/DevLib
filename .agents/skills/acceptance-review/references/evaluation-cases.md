# 验收行为案例

| 输入 | 预期结论 | 禁止误判 |
| --- | --- | --- |
| 构建通过，未执行取消操作 | 构建条件通过，取消行为未验证 | 全部功能通过 |
| 修复后只有旧版截图 | 受影响视觉条件未验证，需新证据 | 复用旧截图证明修复成功 |
| 核心操作测试明确失败 | 本轮验收未通过，指出条件与反例 | 以其他测试通过率掩盖 |
| 用户禁止设备操作 | 允许范围内继续验证，设备项标为未验证并保留排除原因 | 调用 adb 或将排除项写成通过 |
| 本轮用户确认某条操作成功 | 对应条件标注用户确认，其余独立判断 | 宣称 agent 实测并更新自动基线 |
| 只有可选美化建议，其余必需项证据完整 | 本轮范围通过，美化单列 | 将个人偏好当验收阻断 |
| 用户只要求验收 | 核对证据，报告缺陷 | 自动改业务或发布 |

真实验证保留原始任务、产物版本、有效证据与结论。人工推演仅检查规则逻辑，不能证明运行覆盖。与工程评审共用问题定位，与测试报告共用用例 ID。
