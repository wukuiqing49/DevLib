# 数据解释与项目事实

| 数据 | 实际来源及解释边界 |
| --- | --- |
| 产品能力 | 目标项目实际代码、资源及配置；README 和商店声明需要源码交叉核验，演示/计划功能不能当作已发布功能 |
| 用户评价 | reviews.list 取回后本地筛日期/星级；声明取回上限、样本数和时间，不等于完整历史评价 |
| 当前商店文案 | edits.insert 后 listings.get；记录 locale 和来源状态，读取失败不证明 App 未上架 |
| 安装/卸载 | GCS stats/installs 的 country CSV；只合计实际覆盖日期，缺日期不冒充完整周期，不据此推算留存 |
| 搜索词/获客 | GCS stats/store_performance 的 traffic_source CSV；仅 Google Play search 行归属搜索，访问和获客合计后重算转化率，不是全市场搜索量 |
| Other | Traffic source=Other 单列，不能归因到搜索；搜索来源中的聚合词 Other 也不是某个可识别具体关键词 |
| 商店整体评分 | ratings overview 最新 Total Average Rating，附报表日期；不平均每日均分、不推算评分人数，评价样本均分另列 |
| 崩溃/ANR | crashes overview 实际有记录日期的事件数；缺文件/缺记录不证明零事件，不是用户崩溃率 |
| DAU/自然排名 | 当前连接器无对应数据源，不能用活跃设备安装数或搜索访问量替代 |
| 增长/趋势 | 需要同口径可比较周期及覆盖度；单次快照和少量评价不能证明增长或文案效果 |

以实际代码支持的数据源和本次来源状态为准；CSV 格式不匹配、缺列、重复维度或权限失败均应明确记录，不为了填满报告自行猜数。未核实产品能力列为“待确认”，不直接写入建议商店文案。

关键词区分已实现功能直接相关、待验证和不建议使用。不得堆词、虚构功能或承诺排名/转化提升。翻译建议保留母语审校状态。
