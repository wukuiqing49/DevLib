# 源码证据与资源核验

## 按技术栈定位

| 类型 | 优先读取 | 需要确认 |
| --- | --- | --- |
| Android | settings/Gradle、版本目录、Manifest、strings、导航、Activity/Fragment/Compose、assets/drawable | applicationId、选中变体、入口与功能接入；权限不证明产品能力 |
| iOS/macOS | Xcode/Swift Package、Info.plist、SwiftUI/UIKit、路由、Assets、String Catalog | 目标 App、Bundle ID、界面实际可达性 |
| Web | package.json、路由、页面、组件、内容配置、public/assets、服务接口调用 | 官网与产品的边界；客户端按钮不证明服务端可用 |
| 桌面/CLI | 构建清单、启动入口、菜单/命令定义、资源、示例、发布说明 | GUI 或 CLI 定位、实际命令及支持平台 |
| 库/SDK | 公开 API、模块依赖、示例、测试、发布配置、README | 正式公开能力、真实接入步骤、版本与兼容限制 |

先通过文件清单与搜索缩小范围，再读关键实现；避免全仓无差别扫描。跳过构建输出、依赖缓存、私钥和凭据。对 README 与代码冲突，记录差异，以当前选定产品实际实现约束宣传。

## 功能事实

每条功能记录：名称、面向用户的用途、入口、关键实现路径、输入/输出、可证实的限制、是否可达。路径使用相对源项目路径，证据不进入公开页面。技术组件只用于解释用户价值，不逐个作为卖点。

对离线、隐私、安全、准确率、性能、平台支持、定价和商业授权等声明，追查完整链路或明确文档；不能从单个权限、依赖或本地缓存推导。无法证实的声明省略或列入未知项。

## 图片与公开资产

核对图标和截图是否对应当前产品、是否含测试账号/个人数据、是否是已有公开素材。发现敏感内容时选择其他资源或制作经确认的脱敏副本，不修改源图。保留来源到复制文件的映射；不默认使用另一产品的模板图片。

没有截图不是强制停止条件：可以用产品图标、可验证代码例子和文字流程，但不得把生成插图标为真实产品画面。
