# 推送与 Web 桥行为案例

维护 Skill 时可静态推演；宿主接入时按影响选择下表，用现有报告记录构建版本、前提、操作、预期、实际证据及通过/失败/未验证。mock 不能代替 FCM/设备证据，不为执行案例扩大生产发送或设备授权。

| 场景 | 预期结果 | 所需证据 |
| --- | --- | --- |
| 关闭系统通知后回前台 | permission 反映真实状态，运营偏好独立；无重复登记风暴 | 登记调用与系统状态 |
| 关闭运营偏好、Token 刷新、再次启动 | enabled=false，公共 Topic 退订；刷新 Token 不自动重新启用 | SDK/FCM 调用与登记状态 |
| 登录 A 后切 B，点击旧推送 | 页面按当前 B 鉴权，不暴露 A 数据；旧回调不覆盖 B 状态 | 身份与导航测试 |
| 前台、后台、进程回收后点击 | 展示及图标正确，首次 Intent/onNewIntent 都内部打开，返回栈正常 | 三条独立设备证据 |
| 同 ID 重投及两条不同通知 | 按协议去重；不同通知点击目标不串线 | 消息 ID 与点击结果 |
| 发送超时/unknown | 查询原 requestId，不改 ID 盲目重发 | 服务端任务记录 |
| accepted / validate_only 成功 | 仅标对应阶段通过，不宣称设备送达 | 分阶段结果 |
| 可信主框架跳转第三方、iframe 请求 | 第三方/iframe 不能调用桥；跳转后旧文档响应被丢弃 | WebView 安全测试 |
| 重复请求、错 action、非法参数、超时 | 不重复执行，返回可关联错误；超时不自动重试写入 | JS 与原生日志（脱敏） |
| 登录/兑换等待期间离页或销毁 | 清理等待和未提交交互，迟到结果不绑定新页面/账户 | 生命周期测试 |
| 全屏后返回、键盘、横屏、页面错误 | 先退出全屏并恢复工具栏，退出按钮和 Insets 可用 | 设备视觉与交互 |
| 普通浏览器或旧 WebView 不支持桥 | 正常浏览/明确降级，不注入不安全备用桥 | 浏览器/旧 provider 测试 |
| 本地源码与线上 CMS/API 版本不同 | 记录差异，按部署版本核对契约，未知项不标通过 | 版本追溯表 |
| 仅授权测试设备 | 不发送公共 Topic，不执行真实反馈、兑换或付款 | 目标与授权范围检查 |

真实测试前复用目标项目 executionPolicy 与已有授权。DevLib 规则默认不执行 adb/真机；消费项目遵循自身策略。安装或同步 Skill 只授权文件维护，不代表已执行这些联调案例。
