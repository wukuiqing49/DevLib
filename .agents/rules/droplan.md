# DropLAN 离线分发约束

> 历史 DropLAN 专项参考，仅明确指定该产品时适用；不代表 DevLib 当前能力或工程事实。
## 产品与连接

- 需求以 `Android_Offline_File_Distribution_Development_Plan.md` 为准。Android 发送，多端浏览器接收；不要求接收 App、插件、账号或互联网。
- 本地热点、手动系统热点、已有 LAN 为首版连接路径；接收网页、配对、下载、测速均无外部网络依赖。
- 不硬编码网关、接口名或热点凭据，不假设默认 Network 就是热点。地址发现是待实测能力，必须由真实接收端验证可达。
- 手动热点配置未必可读取；未知信息展示未知。释放 reservation 不等于系统热点必然消失，结束分享须确保本应用服务停止。
- 连接人数、授权浏览器会话和活动下载分别统计；撤销会话指撤销访问，不承诺断开其 Wi-Fi。

## 最快可用

- 能力识别、当前路径测速、连接推荐和总耗时估算属于首版核心；不能以未来专用客户端替代。
- 结合可达性、准备成本、有效吞吐、文件大小与并发选择；不按 Android/iOS/Windows 写死最快协议。
- 区分当前实测、历史参考、未比较；只有本轮比较多个路径后才称“本轮已测最快”。未知硬件能力不从 User-Agent 臆测。
- 测速只访问受限的本地鉴权端点，初始预算最多 3 秒或 32MiB；有活动下载时默认复用传输统计。
- 不为单个新接收端切换网络而破坏已有会话。重新连接需要明确操作与影响提示。

## 文件与 HTTP

- 使用 SAF/ContentResolver 授权读取源文件，应用缓存可使用内部文件 API；不申请无关全盘权限，不将 content URI 转为普通路径。
- 离线不可读的云文档应提示准备本地文件，不能在后台联网拉取。
- 使用固定缓冲、Long 偏移与长度、背压和取消；禁止完整文件载入内存或浏览器 Blob。
- 顺序读取、随机访问、可靠内容版本分别报告能力；不支持 seek 时不伪造 Range 支持，源变化不继续不安全续传。
- 正确处理 HEAD、200/206/416、If-Range 与请求取消；ETag 不以不可靠大小/mtime 冒充强验证器。
- 浏览器负责原生下载；服务端发送完成不等于接收落盘。Range 协议正确、浏览器恢复、最终哈希一致分开验收。
- 默认全局 2 个活动文件响应、每接收会话 1 个；原生下载、重复请求与 Range 重试都经过真实调度，SSE 另有限额。
- 文件访问通过不透明 ID 映射；只读禁止上传、删除、改名、任意路径、远程执行。配对/排队/取消可以使用 POST/DELETE，不能删除源文件。

## 安全、归档与生命周期

- 分享与接收会话独立随机凭据，支持过期和撤销；Wi-Fi 密码不代替文件授权。凭据不落日志，HTTP 不宣称端到端加密。
- 使用同源会话与任务归属校验，防越权、跨站、文件名 XSS/头注入与资源耗尽。
- 大文件默认直接下载；ZIP 在 P1B 预生成一次、验证 ZIP64、空间与安全条目名后复用，未完成归档不可发布。
- 前台服务遵守版本权限与实际类型条件；页面重建不重复建服务，退出/网络丢失时关闭流、任务、Socket 与热点请求。
- 进程重启恢复未分享状态，不自动恢复授权。缓存清理不得删除正在读取的归档或用户源文件。
- 所有跨端、锁屏、大文件和推荐速度结论必须有真机证据；P0 未验收不得宣称产品已可用。
